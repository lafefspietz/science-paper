# [science-paper](https://github.com/lafefspietz/science-paper)

Live [LaTeX](https://en.wikipedia.org/wiki/LaTeX) + [Markdown](https://en.wikipedia.org/wiki/Markdown) editor on [web server](https://en.wikipedia.org/wiki/Web_server) with [PHP](https://en.wikipedia.org/wiki/PHP)

# Core Paper Files:

 - [index.html [Web app to edit README.md]](index.html)
 - [README.md [Main Manuscript]](README.md)
 - [php.js [JavaScript library which calls the PHP]](php.js)
 - [save-file.php [PHP script which saves files]](save-file.php)
 - [load-file.php [PHP script which loads files]](load-file.php)
 - [references.html [Web App to edit references.bib]](references.html)
 - [references.bib [BibTex references file]](references.bib)

# Ecosystem

 - [editor.html [Web app to edit all code in system]](editor.html)
 - [list-files.php [PHP script which lists files]](list-files.php)
 - [spore.php [PHP script which replicates system]](spore.php)
 - [spore.json [System manifest]](spore.json)

# External Libraries:
 
  - [codemirror.js [Syntax Highlighting]](https://codemirror.net/)
  - [showdown.js [Markdown to HTML]](https://github.com/showdownjs/showdown)
  - [mathjax.js [Mathematics type setting]](https://www.mathjax.org/)
